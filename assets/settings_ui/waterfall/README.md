# Settings waterfall design

Applied to the existing `res://settings.tscn` on 2026-11-20, using the user's supplied Settings image as the visual reference.

## Assets

- `background_terraces.png`: current sunrise/rice-terraces scenery, mountains, river, wooden huts, and stone path.
- `background.png`: previous church/tropical scenery, retained as an unused alternative.
- `frame.png`: transparent wooden/gold frame, gear/book crest, blank red banner, pale parchment, waterfall inset, and wooden footer.
- `green_row.svg`, `red_button.svg`: native SVG surfaces for the existing controls.
- `music.svg`, `speaker.svg`, `book.svg`, `back.svg`: native SVG icons.
- Corresponding `.import` files are generated by Godot.

The two selected PNGs were generated with the imagegen skill. SVGs extend the project's native UI graphics. All writing and switches are live Godot controls; no ON/OFF labels or hit targets are baked into the PNGs. Existing licensed Titan One and Roboto font assets are reused.

## Integration

`settings.gd` fits a 1086 x 1448 artwork coordinate space inside the available portrait viewport and applies the same scale to control spacing, fonts, and switches. The background covers the screen; the frame keeps its proportions. Android safe-area bounds are used where available, but physical-device rendering has not been tested.

Existing `MusicToggle`, `SfxToggle`, `HelpButton`, `BackButton`, unique-name references, and callbacks are retained. Music/SFX decorative Icon nodes now use TextureRect. How to Play and Back have mouse-ignoring centered icon/caption groups inside their original Buttons.

Audio preferences still use the existing `user://historyroll_settings.cfg` ConfigFile with `audio/music_enabled` and `audio/sfx_enabled`. Existing AudioManager and Music/SFX bus integration are retained. The How to Play overlay, rules, gameplay, progression, and other scenes were not redesigned.
