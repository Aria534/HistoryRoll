SAVE COMPATIBILITY
player_name is an additive optional field in the existing version-3 JSON.
Missing/invalid name values default to empty; old progress is not rewritten just
for opening the app. A confirmed valid edit saves through ProgressManager.
There is no new migration, player account, reward, or progress reset.
Names use Unicode letters/combining marks, ordinary spaces, hyphens, and straight
or curly apostrophes. Outer/repeated ordinary spaces are normalized.
The LineEdit and save validation both enforce the 30-character limit.

CERTIFICATE
Eligibility requires completed_levels to contain every ID from 1 through 6.
highest_unlocked_level and game_completed alone cannot grant it.
Existing completion records remain authoritative, including compatible old saves.
No rewards are granted for viewing the certificate. Replays preserve one-time rewards.
A legacy completer with no name is prompted to enter one before displaying the award.
The player's name is a centered, dark-brown serif Label that shrinks to fit.
All certificate wording is editable Label text; no date/signature fields.
Certificate artwork keeps its landscape aspect inside the portrait application.
Back returns to Level Selection. The existing music preferences apply.

EDITOR / ANDROID
Open player_name_entry.tscn or certificate.tscn directly in the 2D Editor.
All headings, input, name, buttons and certificate text are real Control nodes.
The @tool scripts show complete Editor previews and scale the presentation to fit.
The native LineEdit enables the platform keyboard; Enter/Done submits the name.
Android keyboard-height handling keeps input and Continue above the keyboard,
temporarily hiding the welcome headings while typing.
No manual signal connections or Autoload configuration are needed.

NAME ENTRY REFINEMENT - 2026-11-26

This refinement changes only name entry, its dedicated artwork and identity tests.
- A leaf-free background removes the two gold laurels beside the HistoryRoll logo.
  Its 1024x1536 native proportions and other scenery are preserved. The original
  background remains available. ARTWORK_PROMPTS.txt records the complete edit prompt.

  The only heading is "Enter your name to begin your journey."

  The compact form retains the existing keyboard avoidance and touch targets.
- A mouse press or touch on the existing native LineEdit enters edit mode.
  The I-beam pointer and a steady 3-pixel caret make readiness clear. The placeholder
  hides while editing and returns after editing ends. No new nodes were created.
- Name validation, 30-character limit, saving, Back, Continue, certificate gating,
  native Android keyboard enablement and all navigation destinations are preserved.
- No .tscn, shared theme, ProgressManager or gameplay changes were made.
