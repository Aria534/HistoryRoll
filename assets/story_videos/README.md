# HistoryRoll hero story videos

Place the final Godot-compatible Ogg Theora videos in this folder using these exact names:

- `lapulapu_story.ogv`
- `bonifacio_story.ogv`
- `rizal_story.ogv`
- `antonio_luna_story.ogv`
- `melchora_aquino_story.ogv`
- `mabini_story.ogv`

The reusable player loads only the selected hero's video. Until a file is installed, it shows a safe "Story Video Coming Soon" placeholder state instead of importing an invalid or empty `.ogv` file.

Recommended encoding: Ogg Theora video with Vorbis audio, portrait 9:16, constant frame rate, and a mobile-friendly bitrate.
