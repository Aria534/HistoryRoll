# HistoryRoll answer sound effects

The game includes built-in correct and incorrect answer chimes, so quiz feedback
works offline even when no external sound files are installed.

To replace the built-in sounds, add Godot-compatible Ogg Vorbis files here with
these exact names:

- `correct_answer.ogg`
- `incorrect_answer.ogg`

Both sounds use the existing `SFX` audio bus and respect the Sound Effects
ON/OFF setting. Replacing these files requires no script changes.
